# What is this?
This repository contains a comprehensive list of the fonts available in the Typst web app, their download and license links, and other useful information.

A few of those fonts don't have a direct download link, therefore the existence of this repository. This repository redistributes the font files and license of these (6) missing fonts as GitHub Release artifacts. And uses that same github link in the `fonts_index.json` file.

The goal is to allow an automated script to download all those font files and licenses to a local directory. 

I made this repo to allow the `CACHE_ALL_FONTS` option in [`typst-api`](https://github.com/Mapaor/typst-api).
